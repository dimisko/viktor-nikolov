# Viktor Nikolov

A gritty text-based investigative adventure game set in the heart of Skopje, Macedonia. Partner with Chief Inspector Viktor Nikolov to solve complex crimes using a police dossier-style interface.

## Game Description

You are a Junior Detective transferred from Bitola, assigned to work alongside the legendary but troubled Chief Inspector Viktor Nikolov. Navigate through locations, gather evidence, interrogate suspects, and piece together the truth to solve murder cases in the dark streets of Skopje.

## Features

- **Investigation Mechanics**: Search crime scenes, collect evidence, and uncover clues
- **Dialogue System**: Interact with NPCs through branching dialogue trees
- **Location Exploration**: Visit multiple locations across Skopje to follow leads
- **Evidence Collection**: Build your case by discovering and connecting clues
- **Case Solving**: Accuse the correct suspect with the right motive and evidence

## How to Play

1. Explore locations to find evidence and clues
2. Talk to witnesses and suspects to gather information
3. Search locations for hidden evidence
4. Use your collected evidence to unlock new dialogue options and locations
5. Build your case and make an accusation when you're ready
6. Help Viktor manage his migraines - use the walkman to reduce stress

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- A Gemini API key (for AI features)

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open your browser to `http://localhost:3000`

### Building for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19
- TypeScript
- Vite
- TailwindCSS
